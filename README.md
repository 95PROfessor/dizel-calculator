# Калькулятор расхода дизтоплива

Статический калькулятор для GitHub Pages. Нормы и история хранятся в Google Таблице через Apps Script.

Перед публикацией укажите URL развёрнутого Apps Script в `cloud-config.json`.
Страница `admin/` переводит на форму администратора в Google. Пароли, ключи, пользовательские данные и серверные рабочие файлы в репозитории не хранятся.
